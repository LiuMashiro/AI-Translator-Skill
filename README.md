# AI 翻译 Skill

**AI Translator Skill**

中英高质量双向翻译 Skill。

## 功能

- 七种内置语言风格，包含范例文段，可自动检测或手动指定
- 三步翻译流程：整体理解与名词表构建、初步精翻、审校润色
- 去除 AI 味、欧化中文、中式英语等常见翻译问题的详细说明
- 术语一致性管理
- 格式保留
- 长文本分块翻译与上下文同步
- 隐喻、双关语、成语、文化特定元素、姓名、大数等的处理策略
- 译者注支持
- 惯用形式保留

## 快速使用

1. 导入 skill
2. 让 AI 翻译

## 支持的语言风格

| 风格        | 典型场景             |
| ----------- | -------------------- |
| 正式 / 学术 | 论文、报告、学术文章 |
| 文学 / 美文 | 小说、散文、诗歌     |
| 口语 / 通俗 | 对话、社交媒体、博客 |
| 技术 / 科技 | 技术文档、编程教程   |
| 新闻 / 报道 | 新闻稿、通讯         |
| 商务 / 专业 | 商业报告、财报、邮件 |
| 公文        | 政府文件、政策文件   |

## 翻译流程

1. 整体理解与名词表构建
2. 初步精翻
3. 审校、修订与润色

> AI翻译质量受模型后训练影响很大。选择翻译高质量的模型比提示词更重要。
